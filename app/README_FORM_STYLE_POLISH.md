# 表单样式统一修复

本次只调整前端样式，不修改后端接口、端口、数据库路径或数据库结构。

## 修改内容

- 统一添加课程、编辑课程中的输入框和下拉框样式。
- 下拉框改为圆角控件，使用更柔和的边框、背景、聚焦态和箭头。
- 数字输入框隐藏浏览器原生的上下微调箭头，避免与整体卡片风格冲突。
- 悬浮编辑卡片和添加课程弹窗中的按钮圆角进一步统一。
- 同时适配浅色与深色模式。

## 主要修改文件

- `src/components/CourseEditFields.tsx`
- `src/components/ManualCourseDialog.tsx`
- `src/components/CourseHoverCard.tsx`
- `src/index.css`

## 注意

浏览器原生 `<select>` 展开的系统菜单在不同操作系统上外观不可完全控制。本次已统一网页中可见的下拉控件本体、箭头、边框和聚焦态。
