# 自定义下拉菜单样式修复

本次修复基于 `site_v0_4_course_edit_unified.zip`，撤回上一版对普通输入框、数字输入框和控件本体的额外样式打磨，只处理真正的下拉菜单弹层。

## 修改内容

- 将课程编辑字段中的原生 `<select>` 替换为 `CustomSelect`。
- 下拉菜单弹层改为网页内自绘菜单，不再使用浏览器/系统原生直角菜单。
- 菜单弹层使用圆角、柔和边框、轻阴影、半透明卡片背景和简短淡入动效。
- 统一作用于：
  - 添加课程里的类别、性质、计划学期、学分计入。
  - 悬浮课程卡片编辑态里的同类选项。
- 未修改端口、后端、接口、数据库路径、数据库结构。

## 修改文件

- `app/src/components/CustomSelect.tsx`
- `app/src/components/CourseEditFields.tsx`
- `app/src/index.css`

## 注意

原生 `<select>` 点开后的选项菜单通常由浏览器或操作系统绘制，普通 CSS 无法稳定控制圆角和阴影。本次通过自定义下拉组件解决该问题。
