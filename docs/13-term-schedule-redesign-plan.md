# 学期课表界面重构计划

## 1. 当前问题

### 1.1 顶栏入口不完整

当前顶部导航只有：

```text
时间轴
旅迹
```

“学期课表”只有从时间轴学期卡片右上角进入时才会临时出现，不像一个稳定功能入口。

需要调整为：

```text
时间轴
旅迹
学期课表
```

这样用户在“时间轴”和“旅迹”界面都能直接进入学期课表，而不是必须先回到时间轴找某个学期卡片。

### 1.2 学期课表界面风格不统一

当前 `TermSchedule.tsx` 已经完成了基础功能，但视觉上还比较像“功能原型”：

- 网格感偏硬。
- 页面节奏和时间轴不一致。
- 课程周次分布区像普通表格，不像当前项目已有的时间轴语言。
- 周课表格子缺少层次，课程块和时间轴课程卡片的设计关系不够强。
- 顶部统计、显示控制、周次切换还没有形成统一工具栏。

结论：功能方向是对的，但需要做一次界面设计重构。

## 2. 从时间轴提取的设计语言

学期课表不应重新发明一套界面，而应继承时间轴的设计语言。

### 2.1 页面气质

继续保持：

- 安静、克制、偏工具型。
- 小字号、清晰层级。
- 暖色浅色背景 + 独立白色/深色卡片。
- 低饱和边框。
- 浮层和抽屉使用轻阴影，不做夸张视觉效果。
- SF Mono Medium 字体。

### 2.2 时间轴已有组件语言

可以继承这些元素：

| 时间轴元素 | 学期课表中的对应 |
|---|---|
| 学期列卡片 | 周课表中的每日列 |
| 课程卡片 | 课表中的课程块 |
| 待安排 / 垃圾篓底部 dock | 学期课表底部或顶部的周次控制条可以参考其胶囊式控制 |
| 显示内容下拉菜单 | 课表显示字段控制 |
| 小型统计数字 | 学期课表顶部的课程数、片段数、当前周 |
| hover / 轻阴影 | 课程块 hover 细节 |

### 2.3 不直接照搬的部分

不建议照搬：

- 时间轴的横向 8 学期列布局。
- 时间轴课程卡片的全部字段。
- 底部抽屉结构。

原因：学期课表的核心是“周次 + 星期 + 节次”，它需要更强的网格系统，而不是八列时间线。

## 3. 顶栏入口重构

### 3.1 导航结构

顶部导航固定为：

```text
学旅    时间轴  旅迹  学期课表                         主题切换
```

### 3.2 点击逻辑

点击“学期课表”时：

- 如果用户之前从时间轴进入过某个学期，则保留上一次的学期。
- 如果没有历史选择，则默认进入第 1 学期。
- 页面内部提供学期切换，不要求用户回到时间轴再换学期。

从时间轴学期卡片右上角 `↗` 进入时：

- 直接进入对应学期。
- 顶栏“学期课表”保持 active。

### 3.3 为什么顶栏保留

学期课表不是时间轴的弹窗，也不是课程卡片详情，而是一个独立视图。因此它应当成为顶栏一级入口。

## 4. 学期课表页面信息架构

重构后页面建议分为四个区域：

```text
顶部工具栏
学期选择条
课程周次分布
逐周课表
```

### 4.1 顶部工具栏

结构：

```text
学期课表
2024-2025 第一学期 · 大一上

[课程 11] [片段 20] [当前 第 4 周]       [显示内容 ▾]
```

设计要求：

- 不做大标题英雄区。
- 和时间轴 header 一样紧凑。
- 统计数字保持 `tabular-nums`。
- 显示内容下拉继续用勾选项，不做一键开关。

### 4.2 学期选择条

新增学期切换条：

```text
大一上  大一下  大二上  大二下  大三上  大三下  大四上  大四下
```

状态：

- 有实际课表数据：正常可点击。
- 无实际课表数据：弱化显示，但仍可点击进入空状态。
- 当前学期：使用 `brand` 色或 `bg-sub/10` 的选中态。

这样用户从顶栏进入后，也能直接切换学期。

### 4.3 课程周次分布

当前功能保留，但视觉重做。

不要做成普通表格，而是做成“压缩课程时间轴”：

```text
课程名称       1  2  3  4  5  6 ... 16
微观经济学             ━━━━━━━━━━━
大学英语        ━━━━━━━━━━━━━━━
形势与政策             ━━━━
```

设计细节：

- 左侧课程名称固定窄列。
- 右侧周次为细密网格。
- 课程活跃周用细条或小块，不使用大面积色块。
- 当前周有一条竖向高亮线。
- 点击周次后，下方课表切换。

创新点：

- 可以把课程分布做成“轨道视图”，类似一个小型甘特图。
- 课程行不需要卡片化，减少视觉负担。
- 当前周用贯穿式竖线，而不是只高亮周次按钮。

### 4.4 逐周课表

核心区域。

结构：

```text
          周一     周二     周三     周四     周五     周六     周日
0102
030405
0607
0809
101112
```

设计方向：

- 外层用一个浅边框面板，不要每个格子都像重表格。
- 星期标题像时间轴里的小标题，轻量。
- 节次列靠左，使用 `text-sub`。
- 课程块使用课程卡片语言：圆角小、边框轻、背景淡。
- 课程块不强行显示太多信息，默认显示：
  - 课程名称
  - 地点
  - 教师
  - 节次

显示控制项：

```text
地点
教师
课序号
上课班级
课程性质
周次
```

### 4.5 课程块层级

课程块建议结构：

```text
微观经济学
01-02节 · 首义-文泽212
胡德状
```

如果用户勾选更多字段：

```text
微观经济学
01-02节 · 首义-文泽212
胡德状 · 课序 18
4-15周 · 必修
```

注意：

- 不要一开始显示上课班级，太长。
- 不要显示课程号，除非后续增加显示项。
- 长地点和长班级需要截断，hover 或 title 再看完整内容。

## 5. 排版重构方案

### 5.1 页面宽度

建议沿用时间轴的横向工具感：

```text
min-h-screen px-8 py-6
```

周课表允许横向滚动，但默认桌面宽度下应尽量完整显示。

### 5.2 区块间距

建议：

| 区域 | 间距 |
|---|---:|
| header 到学期选择条 | 16px |
| 学期选择条到周次分布 | 16px |
| 周次分布到周课表 | 20px |
| 面板内边距 | 12-16px |

不要做大块留白，因为这是工具界面。

### 5.3 视觉层级

层级顺序：

1. 当前学期和当前周。
2. 周课表里的课程块。
3. 周次分布。
4. 顶部统计。
5. 显示项控制。

也就是说，用户进入页面后，首先应知道“我现在看的是哪个学期、哪一周”，然后看到课程表。

## 6. 组件拆分计划

当前 `TermSchedule.tsx` 可以继续作为页面入口，但内部应拆分。

建议拆成：

```text
TermSchedule.tsx
  TermScheduleHeader
  TermSelector
  WeekRail
  CourseWeekTracks
  WeeklyScheduleGrid
  ScheduleCourseBlock
  ScheduleDisplayMenu
```

其中：

- `TermSchedule.tsx` 只负责数据加载、状态和组合。
- `WeekRail` 负责周次选择。
- `CourseWeekTracks` 负责上方课程分布。
- `WeeklyScheduleGrid` 负责下方课表网格。
- `ScheduleCourseBlock` 负责单个课程块。

这样后续要加 hover、详情弹窗、冲突提示时，不会继续堆在一个文件里。

## 7. 数据匹配规则

必须继续遵守当前后端口径：

```text
start_week <= selectedWeek <= end_week
start_period <= period <= end_period
```

注意：

- 周次是闭区间。
- 节次也是闭区间。
- `030405` 表示第 3 到第 5 节。
- 不要按左闭右开区间处理。

逐周课表格子匹配建议：

```text
课程 start_period 落入当前节次块，就显示在这个节次块中。
```

原因：第一版不做复杂跨行渲染，避免同一门课在多个节次块重复出现。

## 8. 阶段拆解

### Phase 4.1：顶栏入口

任务：

- 顶栏固定加入“学期课表”。
- 点击后进入学期课表页面。
- 时间轴学期卡片右上角入口保留。
- 从时间轴进入时，自动选中对应学期。

验收：

- 时间轴、旅迹都能看到“学期课表”。
- 从顶栏进入默认显示第 1 学期或上次学期。
- 从学期卡片进入显示对应学期。

### Phase 5.1：页面结构重排

任务：

- 重排 header。
- 新增学期选择条。
- 重新组织统计和显示菜单。

验收：

- 页面第一眼能清楚看到当前学期、当前周。
- 统计区不喧宾夺主。
- 显示菜单位置自然。

### Phase 5.2：课程周次分布重构

任务：

- 把上方周次分布改成轨道式时间轴。
- 当前周使用竖向高亮或强选中态。
- 点击周次切换下方课表。

验收：

- 能看出课程横跨哪些周。
- 不像普通表格。
- 不遮挡课程名。

### Phase 5.3：周课表视觉重构

任务：

- 优化星期列、节次行和课程块。
- 减少硬表格感。
- 统一课程块圆角、边框、背景和 hover。

验收：

- 和时间轴课程卡片属于同一视觉系统。
- 默认显示不拥挤。
- 勾选更多字段后也不明显溢出。

### Phase 5.4：空状态和无数据学期

任务：

- 第 5-8 学期暂无实际课表数据时，显示干净空状态。
- 学期选择条仍保留这些学期，但弱化。

验收：

- 无数据时不报错。
- 用户知道“还没有导入这个学期的实际课表”。

## 9. 暂不做的内容

本次重构先不做：

- 拖拽课程进课表。
- 从课表反向修改时间轴。
- 自动时间冲突处理。
- 课程详情复杂弹窗。
- 移动端专门适配。
- 复杂 CSS 跨行布局。

原因：当前目标是把“学期课表”变成稳定、统一、可用的视图，而不是马上做成完整教务排课系统。

## 10. 最终验收标准

重构完成后应满足：

1. 顶栏始终有“学期课表”入口。
2. 从时间轴和旅迹都能进入学期课表。
3. 从时间轴学期卡片进入时，能定位到对应学期。
4. 学期课表页面视觉上和时间轴、旅迹统一。
5. 上方课程周次分布像“时间轴”，不是普通数据表。
6. 下方周课表清楚展示星期、节次、课程、地点、教师。
7. 显示内容下拉可以单独控制字段。
8. 深色模式下文字、边框、课程块都清晰。
9. `npm run build` 通过。
10. 后端闭区间数据口径不被前端破坏。
